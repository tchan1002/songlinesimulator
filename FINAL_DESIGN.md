# Final Songline Quilt Design - Authentic Structure

## What You'll See Now

### ✅ AUTHENTIC ABORIGINAL SONGLINE:

```
┌─────────────────────────────────────┐
│ ╔═══════════════════════════════╗  │
│ ║   START ◎◎◎                  ║  │
│ ║      ↓                        ║  │
│ ║    ●●●●●                      ║  │
│ ║     ····· ↑                   ║  │
│ ║    ●●●●● ◎◎                  ║  │
│ ║     ····· → ●●●               ║  │
│ ║        ◎◎◎ ····· ↓           ║  │
│ ║          ●●●●●●               ║  │
│ ║            ····· ◎◎           ║  │
│ ║              ●●●              ║  │
│ ║                ◎◎◎ END        ║  │
│ ╚═══════════════════════════════╝  │
└─────────────────────────────────────┘

Legend:
····· = Dotted journey path (flowing line)
●●●●● = Organized dots along path
◎◎◎ = Concentric circles at stops
↑→↓← = Direction arrows
START/END = Labeled waypoints
```

### Key Features:

**1. Clear Journey Path**
- Flowing dotted/dashed lines
- Connects start → waypoints → end
- Colored by transit mode
- Organic curves (not straight)

**2. Organized Dots**
- Follow the path line
- 20-50+ per segment
- NOT scattered randomly
- Match path colors

**3. Concentric Circles**
- At every waypoint
- Traditional Aboriginal marker
- Size = importance (more stops = larger)
- Start/End clearly labeled

**4. Directional Arrows**
- ↑→↓← symbols
- White circles along path
- Show direction of travel
- Easy to follow

**5. Earth Tone Background**
- Warm gradient
- Subtle texture
- Doesn't compete with path
- Traditional feel

## How to Read Your Songline

**1. Find START** (labeled with large circles)

**2. Follow the colored dotted line** through the canvas

**3. Notice:**
- **Dots along path** = journey progression
- **Circles** = stops/waypoints (bigger = more stops)
- **Arrows** = direction of travel
- **Colors** = transit modes (orange=bus, CTA colors=train, gray=walk)

**4. Arrive at END** (labeled with large circles)

You can **trace your entire journey** visually!

## Technical Details

### Path Algorithm:
```javascript
1. Start at (20% width, 30% height)
2. For each segment:
   - Calculate angle from bearing (or organic)
   - Move distance based on duration
   - Add organic curve
   - Stay within bounds
3. Draw dotted line between points
4. Add dots along line
5. Add circles at waypoints
6. Add direction arrows
```

### Visual Elements:
- **Line**: 12px base + 8px dotted top
- **Dots**: 20-50 per segment, 2-4px size
- **Circles**: 3-6 rings, 15-30px radius
- **Arrows**: 16px white circles with symbols
- **Border**: 20px brown with gold dots
