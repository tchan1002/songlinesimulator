## 🎯 What Makes This Special

### Technical Innovation
1. **Pure Web Audio Synthesis** - No audio files, all sounds generated algorithmically
2. **Deterministic Generation** - Same route always creates same output
3. **Real-time Visualization** - Canvas timeline synced with audio playback
4. **Transit Color Mapping** - Uses actual CTA line colors throughout
5. **Mode-based Patterns** - Different geometric shapes for different transit types

### Design Philosophy
- **Collaborative Creation** - Human intent (route) + Machine interpretation (generation)
- **Multi-sensory Experience** - Audio, visual, tactile (downloadable)
- **Cultural Inspiration** - Indigenous Australian songlines reimagined for urban transit
- **Accessibility First** - Keyboard navigation, focus states, semantic HTML
- **Performance Optimized** - 60fps animations, efficient Canvas rendering

## 📖 Quick Start Guide

### For Users

1. **Visit the deployed site** (or run locally)
2. **Enter two Chicago addresses**
3. **Click "Generate Songline"**
4. **Explore your outputs**:
   - View route on map
   - Play audio composition
   - Interact with timeline
   - Download quilt pattern

### For Developers

1. **Get Google Maps API key** → [Google Cloud Console](https://console.cloud.google.com/)
2. **Add key to index.html** (line 130)
3. **Run local server**: `python -m http.server 8000`
4. **Open**: `http://localhost:8000`
5. **Test**: Click "Example Route" → "Generate Songline"

**Full instructions**: [QUICKSTART.md](QUICKSTART.md)
