COLOR LEGEND:
═════════════
🚌 Bus       : Orange (#FF6B35)
🚇 Train     : Line-specific color (Red: #c60c30, Blue: #00a1de, etc.)
🚶 Walking   : Gray (#999999)
🚗 Driving   : Light blue (#87CEEB)

WAVEFORM PATTERNS:
══════════════════
Bus:     \/\/\/\     (Jagged - represents stops and starts)
Train:   ~~~~~       (Sine wave - smooth rail motion)
Walking: ‾‾‾‾‾‾      (Pulse - footsteps)
Driving: ~~~~~~      (Smooth cosine - continuous motion)

INTERACTIVE FEATURES:
═════════════════════
✓ Click anywhere on timeline to set playback position
✓ Hover over segments for tooltips with detailed info
✓ Gold playback indicator shows current position
✓ Transfer markers (○) show mode changes
✓ Segments sized proportionally to duration
✓ Responsive - adapts to container width

SEGMENT DETAILS:
════════════════
Each segment shows:
- Primary text: Route/Line name + stop count OR distance
- Secondary text: Duration in minutes
- Color: Mode-specific or actual CTA line color
- Waveform: Visual pattern representing transit mode
- Borders: Subtle black outlines for definition

TECHNICAL SPECS:
════════════════
Canvas size: 100% width × 180px height
Timeline bar: 60px tall, centered vertically
Margins: 20px left/right
Labels: Below timeline with 2-line layout
Transfer markers: White dots with rings
Playback indicator: 3px gold line with triangles
DPI: High-resolution (devicePixelRatio scaling)

INTEGRATION:
════════════
Automatically renders after route generation
Syncs with window.routeSegments array
Exposes window.updatePlaybackPosition() for audio
Exposes window.resetPlayback() for controls
