# What Your Songline Quilt Should Look Like

## Based on Real Aboriginal Art

You provided a reference image of authentic Aboriginal songline art. Here's what you should see in your generated quilts:

---

## ✅ YOU SHOULD SEE:

### 1. **Multiple Overlapping Circles**
- 6-10 circles (one per route segment)
- Circles of different sizes
- Clearly overlapping each other
- Some circles behind, some in front

### 2. **Concentric Rings**
- Each circle has 3-8 rings
- Like a target or ripple
- Dotted ring outlines
- Rings lighter toward outside

### 3. **Dense Dots Everywhere**
- 800+ small dots scattered
- Dots between circles
- Dots connecting circles
- NO large empty spaces

### 4. **Curved Connections**
- U-shaped curves between some circles
- Dotted/dashed style
- Organic, flowing
- NOT straight lines

### 5. **Radiating Patterns**
- Small dots radiating from each circle center
- 2 rings of dots (8-16 dots per ring)
- Creates energy/movement
- Subtle but visible

### 6. **Earth Tone Colors**
- Warm ochre/tan background
- Brown, orange, yellow, cream
- Plus transit mode colors:
  - Orange = bus
  - CTA colors = train (red, blue, brown, etc.)
  - Gray = walking

### 7. **Authentic Border**
- Brown frame with many dots
- Gold/brown dots in border
- Small corner circles
- Traditional framing

---

## ❌ YOU SHOULD NOT SEE:

### ✗ Single Path from A to B
```
WRONG:  START ──→ middle ──→ END
```
Songlines are about places (circles), not paths!

### ✗ Grid Arrangement
```
WRONG:  ◉  ◉  ◉
        ◉  ◉  ◉
        ◉  ◉  ◉
```
Should be organic, overlapping placement!

### ✗ Empty Spaces
```
WRONG:  ◉              ◉


              ◉
```
Dots should fill the spaces!

### ✗ All Same Size
```
WRONG:  ◉◉◉  ◉◉◉  ◉◉◉
```
Should vary dramatically in size!

### ✗ No Overlapping
```
WRONG:  ◉◉◉   ◉◉◉   ◉◉◉
```
Circles should overlap for depth!

### ✗ Scattered Chaos
```
WRONG:  · ·◉ · ·
        ··· · ◉··
        · ◉· ····
```
Should have structure through circles!
