# Quilt Pattern Visual Examples

## Understanding the Visual Language

This document explains how different Chicago transit routes translate into quilt patterns, helping you understand what to expect when generating your own songlines.

## Pattern Elements Guide

### Geometric Shapes by Mode

#### 1. RAIL (Train Lines) - Concentric Circles
```
Visual: ⊙ Multiple circles from center
Color: Actual CTA line colors
Meaning: Station-to-station journey, radial network
```

**Red Line Example:**
- Color: Deep red (#c60c30)
- Pattern: 4-6 concentric circles
- Size: 1x1 or 2x2 depending on duration
- Represents: Chicago's busiest north-south spine

**Blue Line Example:**
- Color: Bright blue (#00a1de)
- Pattern: 5-7 concentric circles
- Size: Often 2x2 (long rides to O'Hare)
- Represents: Connection to airports

#### 2. BUS - Checkerboard Squares
```
Visual: ▢▣ Alternating colored squares
Color: Orange (#f9461c)
▣▢ Grid pattern
Meaning: Street grid navigation
```

**Typical Bus Patch:**
- Grid: 2x2 to 5x5 small squares
- Alternates: Orange and light orange
- Size: Usually 1x1 patch
- Represents: Local neighborhood connections

#### 3. WALKING - Radiating Triangles
```
Visual: △ Triangles from center
Color: Gray (#6c757d)
Meaning: Human-scale movement
```

**Walking Connection:**
- Pattern: 3-8 triangular wedges
- Colors: Alternating gray and dark gray
- Size: Always 1x1 (short distances)
- Represents: Transfers between transit

#### 4. DRIVING - Nested Hexagons
```
Visual: ⬡ Hexagons within hexagons
Color: Blue (#00a1de)
Meaning: Highway network efficiency
```

**Rare in Chicago Transit Routes:**
- Pattern: 1-3 nested hexagons
- Most Chicago routes avoid driving
- Represents: Express lanes, highways

## Interpreting Your Quilt

### What Makes It Unique?
1. **Color Signature**: Train line colors make each pattern unique
2. **Geometric Rhythm**: Pattern of shapes tells story of journey
3. **Size Variation**: Larger patches = longer segments
4. **Complexity**: More patches = more transfers/segments

### Reading the Pattern
- **Circular patches**: Train rides (check color for line)
- **Checkerboard patches**: Bus segments
- **Triangle clusters**: Walking connections
- **Hexagon patches**: Driving (rare)

### Artistic Interpretation
The quilt is intentionally **non-literal**:
- Not a map (no geographic accuracy)
- Not a diagram (no scale or distance)
- Pure **generative art** from data
- Each journey = unique visual signature

## Size Reference

### Patch Sizes
- **1x1 Standard**: Most segments (< 20 min, < 10 stops)
- **2x2 Large**: Major segments (> 20 min OR > 10 stops)

### Grid Sizes by Route Complexity
- **4x4**: Simple (1-3 segments)
- **6x6**: Moderate (3-5 segments)
- **8x8**: Complex (5-7 segments)
- **10x10**: Very complex (7-9 segments)
- **12x12**: Maximum complexity (9+ segments)

## Download & Display

### Print Recommendations
- **Size**: 600x600px (suitable for 8x8" print at 75 DPI)
- **Format**: PNG with transparency support
- **Use**: Frame, fabric printing, digital art collection

### Viewing Tips
- View at full size to see pattern details
- Zoom to appreciate geometric precision
- Compare different routes to see variations
- Look for color harmonies between patches
